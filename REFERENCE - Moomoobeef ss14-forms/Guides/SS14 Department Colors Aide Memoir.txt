## Styling Combinations

### Medical Document Header
```
[color=#5b97bc][bold]Medical Department[/bold][/color]
```

### Security Notice
```
[color=#8B0000][bold]SECURITY NOTICE[/bold][/color]
```

### Legal Footer
```
[color=#AAAAAA][italic]This document is binding under NanoTrasen law.[/italic][/color]
```

### Engineering Authorization
```
[color=#FFB90F][bold]ENGINEERING REQUISITION[/bold][/color]
```

## Tips

- **Consistency**: Keep the same color for the same department across all documents
- **Contrast**: Pair dark colors with light text and vice versa
- **Subtlety**: Use lighter shades (#666666–#AAAAAA) for disclaimers and fine print
- **Emphasis**: Use bold + color for titles and headers to draw attention

## Color Testing

When creating new department colors, test them in-game to ensure they're readable against both light and dark backgrounds in SS14's UI.
